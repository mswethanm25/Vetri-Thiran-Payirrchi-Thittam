# FitBuddy – AI Fitness Plan Generator using Gemini Models

FitBuddy is a FastAPI + SQLite web application that generates personalized 7-day workout plans and nutrition tips using Google's Gemini 1.5 Pro and Gemini Flash models.

## Features

- ✅ AI-generated 7-day workout plans (Gemini 1.5 Pro)
- ✅ AI-generated nutrition/recovery tips (Gemini Flash)
- ✅ Feedback-based plan refinement
- ✅ SQLite persistence with SQLAlchemy ORM
- ✅ Jinja2 HTML templates (index, result, admin)
- ✅ Admin view of all users & plans
- ✅ REST API endpoints + `/docs` Swagger UI
